# Skills do Debugador

As skills são instruções operacionais para orientar desenvolvimento, revisão e operação do projeto.

## Princípio

Uma skill especializada não substitui as skills base. Ela aplica os princípios gerais a uma tecnologia ou atividade específica.

Fluxo recomendado:

Produto → Arquitetura/Desenvolvedores → Implementação → Qualidade/DBA/DevOps → Release
