# Skill: Produto

## Objetivo
Transformar problemas de engenheiros de software em requisitos claros, verificáveis e priorizáveis.

## Herança
Esta skill orienta as demais skills, mas não define implementação técnica.

## Responsabilidades
- Discovery.
- Problema e hipótese.
- Requisitos funcionais e não funcionais.
- User Stories.
- Acceptance Criteria.
- Priorização.
- MVP e roadmap.
- Métricas e validação.

## Processo
Problema → Hipótese → Necessidade → Requisito → User Story → Acceptance Criteria → Implementação → Validação.

## Regras
Produto define O QUÊ, POR QUÊ, PARA QUEM e COMO SABEREMOS QUE FUNCIONOU.
Produto não deve impor detalhes de implementação sem justificativa de negócio.

## Saída
Problema, objetivo, escopo, critérios de aceitação, restrições, métricas e prioridade.
